# QA en iPhone — UI-01

Las pruebas de escritorio **no sustituyen** la prueba en un iPhone real.
Ninguna casilla se marca sin haberse ejecutado.

## Datos del dispositivo

| Campo | Valor |
|---|---|
| Modelo de iPhone | _pendiente_ |
| Versión de iOS | _pendiente_ |
| Navegador | Safari |
| URL probada | _pendiente (vista previa no autorizada aún)_ |
| Fecha | _pendiente_ |
| Tiempo de carga aproximado (wifi / datos) | _pendiente_ |

## Lista de pruebas

| # | Prueba | Resultado esperado | Resultado |
|---|---|---|---|
| 1 | Abrir la URL en horizontal | Carga y aparece "Toca para comenzar" | ☐ |
| 2 | Abrir la URL en vertical | Aparece "Gira el teléfono" (también durante la carga) | ☐ |
| 3 | Girar a horizontal tras la prueba 2 | El aviso desaparece y el juego sigue sin recargar | ☐ |
| 4 | Isla dinámica / muesca a la izquierda | Ningún texto ni botón queda tapado | ☐ |
| 5 | Girar 180° (isla a la derecha) | Ningún texto ni botón queda tapado | ☐ |
| 6 | Barra de inicio (línea inferior) | No tapa ningún botón | ☐ |
| 7 | Barras de Safari visibles | Todo cabe sin recortes | ☐ |
| 8 | Barras de Safari ocultas (menú "aA" → Ocultar barra) | Todo cabe y se reajusta | ☐ |
| 9 | Tocar "Toca para comenzar" | Abre el menú principal | ☐ |
| 10 | "Continuar" y "Ajustes" | Se ven deshabilitados y no hacen nada | ☐ |
| 11 | Nueva partida → Volver al menú, 10 veces | Sin cierres ni bloqueos | ☐ |
| 12 | Pellizcar o tocar dos veces la pantalla | La página no se amplía | ☐ |
| 13 | Compartir → "Añadir a pantalla de inicio" y abrir desde el icono | Funciona a pantalla completa | ☐ |
| 14 | Legibilidad | Todos los textos se leen sin ampliar | ☐ |
| 15 | Tamaño de los botones | Se pulsan con el pulgar sin errores | ☐ |
